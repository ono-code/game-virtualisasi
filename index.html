Modul Pembelajaran Linux, VirtualBox & Remote SSH

Pelajari konsep dasar sistem operasi Linux, tata cara virtualisasi dengan Oracle VM VirtualBox, langkah instalasi server/desktop, hingga manajemen server jarak jauh menggunakan SSH Client.

BAB 1

Pengenalan Sistem Operasi Linux

Linux adalah sistem operasi berarsitektur UNIX open-source yang dikembangkan pertama kali oleh Linus Torvalds pada tahun 1991. Karena bersumber terbuka (open-source) di bawah lisensi GNU General Public License (GPL), Linux bebas untuk dikembangkan, dimodifikasi, dan didistribusikan ulang oleh siapa saja.

Perbandingan Linux Desktop vs. Linux Server

Parameter Linux Desktop Linux Server
Antarmuka (UI) Graphical User Interface (GUI) Command Line Interface (CLI)
Penggunaan Resource RAM & CPU relatif lebih besar (rendering grafis) Sangat efisien, ringan, hemat RAM/Storage
Tujuan Utama Produktivitas harian, multimedia, browsing Hosting web, database, routing, file sharing
Contoh Distro Ubuntu Desktop, Linux Mint, Fedora Debian Server, Ubuntu Server, Rocky Linux
Catatan Penting TKJ: Di dunia industri dan infrastruktur jaringan, mayoritas server dijalankan menggunakan antarmuka CLI (Command Line Interface) tanpa tampilan grafis demi alasan stabilitas, efisiensi konsumsi RAM, dan tingkat keamanan yang lebih tinggi.
BAB 2

Instalasi VirtualBox & Pembuatan Mesin Virtual (VM)

Virtualisasi adalah teknologi yang memungkinkan kita menjalankan satu atau lebih sistem operasi (Guest OS) di atas sistem operasi utama (Host OS) secara bersamaan pada satu perangkat keras fisik.

Langkah Membuat Mesin Virtual (VM) Linux Server:

  1. Buka aplikasi Oracle VM VirtualBox, lalu klik tombol New (Baru).
  2. Masukkan nama VM (contoh: Linux-Server-TKJ), pilih Type: Linux, Version: Debian (64-bit) / Ubuntu (64-bit).
  3. Alokasikan memori RAM (Disarankan minimal 1024 MB / 1 GB untuk Server CLI).
  4. Pilih opsi hard disk Create a virtual hard disk now dengan tipe file VDI (VirtualBox Disk Image).
  5. Pilih penyimpanan Dynamically Allocated dengan alokasi ruang berkisar 20 GB.

Konfigurasi Network Adapter VirtualBox (Sangat Penting!)

Agar komputer Host (laptop/PC Anda) dapat berkomunikasi dan melakukan SSH ke mesin virtual Linux Server, pahami 3 mode jaringan utama:

Mode NAT
NAT (Default)

VM bisa mengakses internet melalui Host, namun Host TIDAK BISA melakukan SSH langsung ke IP VM secara default tanpa port forwarding.

Rekomendasi Praktikum
Host-Only Adapter

Membuat jaringan terisolasi khusus antara Host dan Guest VM. Sangat cocok untuk praktikum Remote SSH dari Laptop Host!

Mode Bridge
Bridged Adapter

VM seolah-olah terhubung langsung ke router fisik yang sama dengan Host dan mendapatkan IP dari DHCP router fisik.

BAB 3

Tata Cara Instalasi Linux Desktop & Server

1. Tahap Persiapan File ISO

Masukkan berkas image ISO ke dalam Virtual CD Storage pada VirtualBox: pilih VM $\rightarrow$ Settings $\rightarrow$ Storage $\rightarrow$ Klik icon Disc Kosong $\rightarrow$ Pilih Choose a disk file (Pilih ISO Debian/Ubuntu).

2. Langkah Instalasi Linux Server (Debian/Ubuntu CLI):

  • Pilih menu boot Install atau Graphical Install.
  • Pilih Bahasa (English disarankan), Lokasi (Indonesia), dan Layout Keyboard (American English).
  • Isi Hostname (misal: server-tkj).
  • Atur kata sandi untuk akun root (Superuser) dan buat akun pengguna biasa (misal: siswa).
  • Partisi Disk: Pilih metode Guided - use entire disk untuk pemula. Pilih Finish partitioning and write changes to disk.
  • Software Selection (Penting!): Hilangkan centang pada Desktop Environment (GUI), lalu pastikan mencentang [*] SSH server dan [*] standard system utilities.
  • Pasang Bootloader GRUB pada hard disk virtual utama (/dev/sda).
  • Selesai instalasi, unmount file ISO dan reboot VM.

3. Langkah Instalasi Linux Desktop (GUI):

Pada instalasi Linux Desktop (seperti Ubuntu Desktop atau Linux Mint), proses jauh lebih visual. Anda cukup memilih Try or Install Ubuntu, menentukan zona waktu secara grafis, membagi partisi otomatis, dan menunggu penyalinan berkas hingga reboot.

BAB 4

Konfigurasi Jaringan & Remote Server via SSH

SSH (Secure Shell) adalah protokol jaringan terenkripsi yang digunakan untuk mengoperasikan layanan komputer secara jarak jauh (remote control) berbasis baris perintah (CLI). SSH bekerja secara default pada Port 22.

1. Mengecek Alamat IP di Linux Server

Login ke server Linux Anda, lalu jalankan perintah:

ip a

Catat IP Address yang tertera pada interface Host-Only (misal: 192.168.56.10).

2. Memastikan Service SSH Aktif

Cek status service OpenSSH Server:

sudo systemctl status ssh

Jika status belum aktif, jalankan perintah:

sudo systemctl start ssh
sudo systemctl enable ssh

3. Melakukan Remote SSH dari Komputer Host

Buka Command Prompt / PowerShell di Laptop Host Anda, ketikkan perintah:

ssh siswa@192.168.56.10

Ganti siswa dengan username server Anda dan 192.168.56.10 dengan IP Server VM Anda.

Tips Tambahan: Anda juga bisa menggunakan aplikasi client berbasis GUI seperti PuTTY dengan mengisi Host Name: 192.168.56.10, Port: 22, dan Connection Type: SSH.
